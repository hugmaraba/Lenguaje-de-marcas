
# Ejercicio 3 - Parte B

## Overflow

- visible: el contenido sobresale de la caja.
- hidden: el contenido que sobresale queda oculto.
- scroll: aparecen barras de desplazamiento.
- auto: aparecen barras cuando son necesarias.

En este ejercicio utilizamos overflow: auto.

## Visibility hidden y Display none

visibility: hidden oculta el elemento pero mantiene
el espacio que ocupaba en la página.

display: none oculta el elemento y elimina también
el espacio que ocupaba en la página.
