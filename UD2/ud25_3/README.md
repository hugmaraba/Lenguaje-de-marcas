
# Ejercicio 3 - Parte A

## Etiqueta sobre la tarjeta

La tarjeta utiliza position: relative para que la etiqueta
se posicione respecto a ella.

La etiqueta utiliza position: absolute, top: -10px
y right: -10px para sobresalir de la esquina superior derecha.

Si ponemos overflow: hidden en la tarjeta, la parte que
sobresale de la etiqueta queda cortada.

Para solucionarlo podemos quitar overflow: hidden
de la tarjeta.
