
# Ejercicio 2 - Universo Gaming

Página web temática sobre el mundo gaming para practicar
position: sticky, position: fixed y scroll.

## Contenido

La página tiene un banner inicial, un menú con cuatro enlaces
y cuatro secciones: videojuegos, hardware gaming, esports
y comunidad gaming.

## Sticky

El menú utiliza position: sticky y top: 0 para quedarse
pegado en la parte superior de la pantalla cuando hacemos scroll.

El z-index evita que otros elementos se coloquen por encima
del menú.

## Fixed

El botón Subir utiliza position: fixed para mantenerse
en la esquina inferior derecha de la pantalla.

## Diferencia entre sticky y fixed

Sticky mantiene la posición normal del elemento hasta que
llega al límite indicado y después se queda pegado.

Fixed mantiene el elemento fijo respecto a la pantalla
y sale del flujo normal del documento.
