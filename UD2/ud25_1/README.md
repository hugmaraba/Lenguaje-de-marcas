# Ejercicio 1 - Laboratorio de Position

## Static
Cuando se utiliza position: static, el elemento mantiene su posición
normal. Las propiedades left, right, top y bottom no funcionan.

## Relative
Con position: relative, el elemento se desplaza respecto a su
posición original. El espacio que ocupaba sigue reservado.

## Absolute
Con position: absolute, el elemento sale del flujo normal de la página.
Se coloca respecto al elemento padre que tenga position: relative.

## Z-index
El z-index permite controlar qué elemento aparece por encima de otro.
En este ejercicio el cuadro 1 aparece por encima del cuadro 2
porque tiene un z-index mayor.
