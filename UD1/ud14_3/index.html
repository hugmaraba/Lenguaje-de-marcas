1. HTML

HTML es un lenguaje de marcado que se utiliza para crear la estructura de las páginas web. Permite añadir títulos, párrafos, imágenes, enlaces, listas y tablas.

Los elementos HTML se escriben mediante etiquetas. Por ejemplo, h1 sirve para crear un título principal y p se utiliza para escribir un párrafo.

También podemos utilizar la etiqueta a para crear enlaces a otras páginas. Para insertar imágenes utilizamos img, mientras que ul y li permiten crear listas.

Ejemplo de HTML

<h1>Mi primera página</h1>
<p>Bienvenido a mi página web.</p>
<a href="https://www.w3.org/">Visitar W3C</a>

En este ejemplo utilizamos h1 para crear un título, p para escribir un párrafo y a para añadir un enlace.

2. CSS

CSS es un lenguaje que permite dar estilo a las páginas web. Con él podemos cambiar los colores, los tamaños de letra, los márgenes y los fondos.

Podemos escribir los estilos dentro de la etiqueta style o guardarlos en un archivo CSS independiente.

CSS también permite organizar los elementos de una página y adaptar su diseño a diferentes tamaños de pantalla.

Ejemplo de CSS

p {
    color: blue;
    font-size: 20px;
}

En este ejemplo, todos los párrafos tendrán el texto de color azul y un tamaño de letra de 20 píxeles si aplicamos estas reglas.

3. JavaScript

JavaScript es un lenguaje de programación que permite añadir interactividad a las páginas web. Por ejemplo, podemos mostrar mensajes, validar formularios y responder a las acciones del usuario.

JavaScript puede modificar el contenido de una página sin necesidad de recargarla por completo.

HTML proporciona la estructura, CSS controla la apariencia y JavaScript permite añadir comportamientos interactivos.

Ejemplo de JavaScript

function saludar() {
    alert("¡Hola! Bienvenido a mi página web.");
}

En este ejemplo creamos una función llamada saludar. Cuando se ejecuta, muestra un mensaje de bienvenida en una ventana emergente.

Otros usos de JavaScript

  • Validar los datos de un formulario.
  • Mostrar mensajes al usuario.
  • Modificar el contenido de una página.
  • Crear animaciones e interacciones.
  • Comprobar los datos introducidos por el usuario.

4. Herramientas de desarrollo

Visual Studio Code es un editor de código que permite crear páginas web con HTML, CSS y JavaScript.

Live Server es una extensión que permite abrir una página en el navegador y visualizar los cambios al guardar el archivo.

El validador del W3C permite comprobar si un documento HTML cumple las normas del lenguaje y ayuda a detectar errores.

Las herramientas para desarrolladores del navegador permiten inspeccionar elementos, revisar estilos y encontrar problemas. Normalmente se abren pulsando F12.
