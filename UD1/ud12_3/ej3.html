Ficha técnica de Python

Información general

Python es un lenguaje de programación creado por Guido van Rossum. Su primera versión pública se publicó el 20 de febrero de 1991.

Python es un lenguaje interpretado, es decir, un programa que ejecuta las instrucciones del código sin necesitar una compilación tradicional previa a código máquina.

Se utiliza en desarrollo web, inteligencia artificial, automatización y análisis de datos. También es compatible con muchas herramientas de desarrollo, como un IDE.

Ejemplo de código

Este programa muestra un mensaje por pantalla:

print("Hola, mundo")

Atajos de teclado

Para guardar un archivo en muchos editores de código, puedes utilizar la combinación de teclas Ctrl + S.

Conceptos técnicos

La variable es un espacio con nombre que permite almacenar un valor para utilizarlo durante la ejecución de un programa.

En Python, una potencia se puede expresar utilizando el operador **. Por ejemplo, 2 ** 3 da como resultado 8, es decir, 23.

La versión 3.13 de Python es una de las versiones de la serie 3 del lenguaje.
