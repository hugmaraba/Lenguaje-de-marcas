Mis trabajos

En esta sección presento algunos proyectos informáticos realizados durante mis estudios.

1. Página web personal

Este proyecto consiste en crear una página web utilizando HTML. Incluye títulos, párrafos, listas y enlaces entre diferentes documentos.

El objetivo es aprender a estructurar páginas web y utilizar correctamente los enlaces internos y externos.

2. Diseño de una red informática

Este trabajo consiste en diseñar una red informática para una empresa, organizando los ordenadores, los switches, el router y los puntos de acceso Wi-Fi.

El objetivo es conseguir una red organizada, segura y que permita conectar todos los dispositivos.

3. Aplicación Vitalcheck

Vitalcheck es una propuesta de aplicación que permite organizar recordatorios y consultar información general relacionada con el cuidado de la salud.

El objetivo es diseñar una aplicación sencilla, accesible y fácil de utilizar.
