UD 2.1 - Ejercicio 1: Tres formas de incluir CSS

1. ¿Cuál es la forma más cómoda para cambiar el color del título en 10 páginas? ¿Por qué?

La forma más cómoda es utilizar CSS externo, porque las diez páginas pueden compartir el mismo archivo CSS. Si quiero cambiar el color del título, solo tengo que modificar la propiedad `color` en ese archivo y el cambio se aplicará a todas las páginas que lo tengan enlazado.

2. ¿Por qué se desaconseja utilizar CSS en línea?

Se desaconseja porque hay que escribir los estilos en cada elemento HTML. Esto hace que el código sea más difícil de mantener y que resulte más complicado modificar los estilos de muchas páginas. Además, mezcla el contenido HTML con los estilos CSS.
